# ◆ SIGNUM

**Tokyo Equity Setup Scanner** — 並列バッチDL + ThreadPoolにより、
東証全銘柄 (約 4,000 銘柄) のスクリーニングを 2〜3 分で実行する Streamlit ローカルアプリ。

## 起動

```powershell
cd <このフォルダ>
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。

## 初回起動時のフロー

1. アプリ起動。ユニバースが 500 銘柄未満なら **赤色のバナー** が表示される
2. 「🌐 JPX から東証全銘柄を取得」ボタンを押す
3. 30 秒ほどで `universe.csv` が東証全銘柄 (約 4,000 銘柄) に更新される
4. ページを再読み込み → スクリーナータブで「評価する銘柄数」が自動的に全件 (4,000+) になる
5. 「🚀 スクリーニング実行 (並列)」をクリック

## CSV 結果の保存先

```
<アプリフォルダ>/outputs/
└── screening/
    ├── 2026-05-02/
    │   ├── 20260502141502.csv
    │   └── 20260502153020.csv
    └── 2026-05-03/
```

- 「💾 CSV保存」ボタンを押すと、その日付のフォルダに `yyyymmddhhmmss.csv` が自動生成
- 「🗂 保存履歴」タブで過去の結果を一覧表示 + プレビュー可能

## 並列スクリーナーの仕組み

```
Stage 1  yf.download をバッチ送信 (一度に 80 銘柄、yfinance 内部並列)
        4000 銘柄 / 80 = 50 リクエスト ≒ 60〜90 秒
Stage 2  履歴ベースの粗フィルタで 80% 以上を即座に除外 (ms単位)
Stage 3  生き残った銘柄のみ ThreadPoolExecutor で info / 四半期PL を並列取得
        数百銘柄 / 10 ワーカー ≒ 30〜90 秒
合計     2〜3 分で全銘柄スクリーニング完了 (逐次の 30〜45 倍速)
```

サイドバーで **バッチサイズ (20-200)** と **並列ワーカー数 (2-24)** を調整可能。

## チューニング指針

| 状況 | バッチ / ワーカー |
|---|---|
| 標準 (高速) | 80 / 10 |
| 安定重視 | 40 / 6 |
| 限界突破 | 150 / 20 |
| レート制限頻発 | 30 / 4 |

## ファイル構成

| ファイル / ディレクトリ | 役割 |
| --- | --- |
| `app.py` | Streamlit アプリ本体 |
| `analysis.py` | データ取得・指標計算・並列スクリーニング |
| `build_universe.py` | JPX から東証全銘柄を取得して universe.csv を更新 |
| `universe.csv` | スクリーニング対象銘柄ユニバース |
| `paid_so.csv` | ストックオプション関連 IR の登録 CSV |
| `outputs/screening/yyyy-mm-dd/` | スクリーニング結果の自動保存先 |
| `requirements.txt` | 依存パッケージ |

## 機能ハイライト

- 東証全銘柄ユニバース (JPX 公式から自動生成)
- 並列スクリーナー (2〜3 分で全銘柄評価)
- ドローダウン / 時価総額 / 出来高 / テーマ フィルタ
- 出来高サージ (10/60d、デフォルト OFF)
- 戦争・GAFA連動セクター除外
- ストックオプション関連 IR (有償/無償/新株予約権)
- 黒字転換 (直近四半期で経常利益が黒字転換)
- RR スコア (0〜100、ドローダウン × 出来高サージ × ボラ × テーマ × カタリスト)
- CSV 自動保存 (日付別ディレクトリ)

## 注意事項

- データは **yfinance (Yahoo Finance) の遅延データ**。リアルタイム判断には不向き。
- 並列実行でレート制限が出ることがあります。エラー時は数分待つかワーカー数を下げてください。
- 本アプリは情報提供のみを目的とし、特定銘柄の売買を推奨するものではありません。
- 投資判断はご自身の責任で行ってください。
